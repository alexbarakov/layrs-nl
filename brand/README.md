# LAYRS brand

Logo «Отражение»: the word LAYRS stands on a canal; its reflection breaks into thinning, fading stripes —
what lies beneath the surface of the city. Slogan: **Look at your city like never before.**
(RU: «Посмотри на свой город по-новому.» NL: «Zie je stad als nooit tevoren.»)

| File | Use |
|---|---|
| `logo.svg`, `logo.png` | wordmark on light |
| `logo-dark.svg`, `logo-dark.png` | wordmark on ink |
| `logo-slogan.svg`, `logo-slogan.png` | wordmark with the slogan |
| `icon.svg` | app icon (`app/assets/images/icon.png`, favicon) |
| `icon-dark.svg` | icon on ink |
| `icon-foreground.svg`, `icon-monochrome.svg` | Android adaptive icon layers |

Colours: ink `#1d1b17`, paper `#f3efe4`, Delft blue `#1f4f96` (on dark `#8fb2e6`).
Letters are Manrope ExtraBold (SIL OFL) converted to paths. Rebuild everything with `python brand/build.py`
(needs `fonttools`, `rsvg-convert`, and `app/node_modules` installed).
